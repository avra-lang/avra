# Avra — the tour

**One program. A greenhouse full of robots, the model that sees for
them, the cluster that teaches it, the app a grower holds, the agent
that answers the phone, and the machines it all runs on. One file.
One compiler. No framework, no runtime, no YAML.**

This is Avra once every design under `docs/` has landed. Some of what
follows compiles today; most of it is designed and waiting its turn.
The last section maps every construct to its design and its status,
so nothing here is a promise without an address.

---

## The world

*Orchard* runs a glasshouse of tomato vines. Forty robots drive the
rows. Each one sees a truss, decides if it is ripe, reaches, cuts and
places, at 100 Hz, without ever swinging an arm through a person.
Every night the day's photos train a better ripeness model on a GPU
cluster, and every morning the fleet wakes up smarter. The grower
watches it all from a phone, and asks an agent when something looks
wrong.

In most stacks that is eleven languages and forty config files: C++
on the robot, Python for the model, CUDA for the kernels, TypeScript
for the app, Swift for iOS, SQL, Terraform, YAML, a job scheduler, a
message broker, and the glue that holds them together and breaks at
3 a.m.

In Avra it is this.

## The program

```avra
//! Orchard — a harvesting fleet, its eyes, its teacher, its grower's app.
//! Every layer below is one program; the compiler sees all of it.
//! (Small helpers — `occupancy`, `last_known`, `midnight` — are elided;
//! every other name is declared here or comes from a package.)

use @std.time.{within, every, ms, secs, hours, Duration}
use @std.task.{all, race, Channel, Tasks}
use @std.tensor.{Tensor, conv, relu, pool, softmax, cross_entropy}
use @std.cluster.{join_cluster, rank}
use @std.data.{Shards}
use @std.http.{server, api, get, post, ok}
use @std.ui.{app, screen, view, column, row, text, image, button, chart, map}
use @std.sqlite.{model, sql}
use @std.ai.{agent, tool}
use @std.deploy.{deploy, service, fleet, database, secret}
use @std.cli.{cli, command, flag, arg}
use @std.errors.{Error, Transient, handler, retry, abort}
use @fleet.arm.{Arm, Joint}                // a vendor's C driver, wrapped (§ the wall)


// ══ 1. THE WORDS — types that mean something ═════════════════════════

type Meters  = float where it >= 0.0
type Radians = float where -3.1416 <= it && it <= 3.1416
type RobotId = int
type VineId  = int
type Ripeness = float where 0.0 <= it && it <= 1.0

/// A reading off the arm, as the driver answers it.
type Pose = { joints: List<Radians>, tip: Point, speed: Meters }
type Point = { x: Meters, y: Meters, z: Meters }

/// One frame from the wrist camera: 3 channels, 224 × 224, a shape the
/// compiler knows — a wrong one is refused where it is passed.
type Frame = Tensor<float, [3, 224, 224]>

enum Verdict {
    Ripe(confidence: Ripeness)
    Green
    Blocked(by: Obstacle)
}

enum Obstacle { Person Vine Robot Unknown }


// ══ 2. THE LAWS — what must hold, written once, checked forever ══════

/// No arm moves faster than 0.5 m/s when a person is within two metres.
law gentle_near_people {
    for pose: Pose, nearest: Meters where nearest < 2.0
    commanded(pose, nearest).speed <= 0.5
}

/// A planned reach never ends inside a vine's volume.
law reach_is_clear {
    for target: Point, vines: List<Vine>
    vines.all(!it.contains(plan_reach(target, vines).end))
}

/// The ripeness model is a probability: its outputs sum to one.
law classes_sum_to_one {
    for f: Frame
    (classify(weights(), f).sum() - 1.0).abs() < 1e-5
}


// ══ 3. THE DATA — declared once, a table, a migration, an API ════════

model Harvest {
    robot: RobotId
    vine: VineId @indexed
    ripeness: Ripeness
    grams: int
    at: Time @auto
}

model Alert {
    robot: RobotId
    what: string
    at: Time @auto
    seen: bool = false
}

/// The day's yield, in the query language the database speaks — typed,
/// the hole a checked argument, never a string glued in.
fn yield_since(db: Db, since: Time) -> List<Row> {
    sql { SELECT vine, SUM(grams) AS grams FROM harvest WHERE at > ${since} GROUP BY vine }
}


// ══ 4. THE FAILURES — errors are values, handled where they're decided ═

@derive(Error)                                           // kind + message rows, one per variant
enum ArmError { Stalled(joint: int), Overcurrent(amps: float), Unreachable(to: Point) }

@derive(Error)
enum SensorError { Occluded, Dropped(frames: int) }

impl Transient for SensorError {                         // "worth trying again" is a trait
    fn transient() -> bool { self is .Dropped }
}

/// One recovery policy, named once, applied anywhere with `catch with`.
const steady = handler {
    .Dropped(n) -> retry(max: 2, backoff: ms(1))          // a transient, tried again
    .Occluded -> abort .Occluded                          // the caller decides
}

/// The robot's state, told to whoever asks — the grower, the agent, the API.
/// No error type written: the compiler infers the union (`ArmError | NotFound`).
fn state_of(id: RobotId) -> Result<RobotState, _> {
    let link = fleet.link(id)? context "reaching robot ${id}"
    let pose = link.pose()? context "reading its arm"
    RobotState.of(id, pose)
}


// ══ 5. THE ROBOT — 100 Hz, no allocation, no surprises ═══════════════

/// The control loop. `every` is a library component: a timer, a deadline
/// per tick, and a report when a tick is late.
every ms(10) {
    on tick { control() }
    on late(by) { log.warn("tick ${by.ms} ms late") }     // spoken, never swallowed
}

/// One tick. The budget is part of the signature: proven, or refused.
/// No `Result` in the signature means TOTAL: every failure that can
/// reach this fn is handled inside it, and the compiler proves it.
@cost(heap: 0, steps: ms(2))
fn control() {
    let pose = arm.read() catch { arm.hold() }            // a failed read: freeze, never guess
    let nearest = lidar.nearest_person() catch 0.0        // blind is treated as "someone is here"
    let verdict = look(camera.frame() catch with steady) catch .Occluded -> Verdict.Green
    atomic {                                             // no pause point in here
        arm.command(commanded(pose, nearest), verdict) catch {
            .Stalled(j) -> arm.release(j)
            .Overcurrent(_) -> arm.brake()
            .Unreachable(_) -> arm.home()
        }
    }
}

/// The only way a speed reaches a motor. The law above holds it.
fn commanded(pose: Pose, nearest: Meters) -> Pose {
    let cap: Meters = if nearest < 2.0 { 0.5 } else { 1.5 }
    pose with { speed: min(pose.speed, cap) }
}

/// Where to reach: A* over the row's occupancy, on the cores.
fn plan_reach(target: Point, vines: List<Vine>) -> Path {
    let grid = occupancy(vines)
    parallel {                                           // both halves join at `}`
        let from_left  = search(grid, left_of(target))
        let from_right = search(grid, right_of(target))
    }
    shorter(from_left, from_right)
}


// ══ 6. THE EYES — a model, on the robot's own GPU ════════════════════

type Weights = {
    c1: Tensor<float, [16, 3, 3, 3]>,
    c2: Tensor<float, [32, 16, 3, 3]>,
    fc: Tensor<float, [32 * 54 * 54, 3]>,
}

/// Three classes: ripe, green, something in the way.
@derive(Grad)                                            // training gets `classify_grad`
fn classify(w: Weights, f: Frame) -> Tensor<float, [3]> {
    let h = pool(relu(conv(f, w.c1)))
    let g = pool(relu(conv(h, w.c2)))
    softmax(matmul(g.flatten(), w.fc))
}

fn look(f: Frame) -> Verdict {
    let p = on .gpu { classify(weights(), f) }           // pinned: the wrist's Jetson
    when {
        p[2] > 0.5 -> Verdict.Blocked(by: .Unknown)
        p[0] > 0.8 -> Verdict.Ripe(confidence: Ripeness(p[0]))
        _ -> Verdict.Green
    }
}

/// The weights the fleet runs: baked into the binary at build time.
const WEIGHTS: Weights = decoded(embed("models/ripeness.params"))
fn weights() -> Weights { WEIGHTS }


// ══ 7. THE TEACHER — every night, 4 nodes × 8 GPUs ═══════════════════

train ripeness {
    data: Shards("s3://orchard/frames", labels: "s3://orchard/labels")
    runs_on: cluster("gpu-pool", nodes: 4, gpus: 8)
    epochs: 20
    learning_rate: 0.01
    seed: 17                                             // same bits on 1 GPU or 32
    step(w, batch) {
        classify_grad(w, batch.frames, loss: cross_entropy(labels: batch.labels))
    }
    on epoch(n, loss) {
        metrics.record("loss", loss)
    }
    on done(w) {
        publish(w, "models/ripeness.params")             // tomorrow's build embeds it
    }
}


// ══ 8. THE FLEET TALKS — a contract, a server, a client for free ═════

api fleet_api {
    @get("/robots/{id: RobotId}")
    fn robot(id: RobotId) -> Result<RobotState, _> { state_of(id) }

    @get("/harvest/today")
    fn today() -> List<Row> { yield_since(db, midnight()) }

    @post("/robots/{id: RobotId}/stop")
    @auth(grower)
    fn stop(id: RobotId) -> Result<RobotState, _> {
        let r = state_of(id) catch .Offline -> last_known(id)?   // recover one kind, pass the rest on
        fleet.send(id, .Stop)
        errdefer fleet.send(id, .Resume)                  // a stop that fails later is undone
        r
    }
}

server orchard {
    port: 8080
    serves: fleet_api
    within: secs(2)                                      // every request has a deadline
    middleware log { on request(req) { access.record(req) } }
}

/// Alerts fan out to phones; a slow phone never slows a robot.
queue alerts of Alert {
    retries: 5
    backoff: secs(2)
}
worker notifier {
    reads: alerts
    at_once: 32
    each alert { push.send(alert.robot, alert.what) }
}


// ══ 9. THE GROWER'S HAND — one UI, native on every screen ════════════

app orchard_app {
    name: "Orchard"
    needs: [network, notifications]

    screen fleet {
        state robots: List<RobotState> = []
        on appear { self.robots = fleet_client.robots()? }
        column {
            text "Today: ${self.robots.length} robots"
            chart { series: fleet_client.today()?, x: .vine, y: .grams }
            for r in self.robots {
                robot_row(r)                               // a plain fn, composed
            }
            if self.robots.any(it.alert != null) {
                text "Something needs you" { color: .red }
            }
        }
    }

    screen robot(id: RobotId) {                          // a typed route: a deep link
        state r: RobotState? = null
        on appear { self.r = fleet_client.robot(id).ok() }
        column {
            image r?.camera
            map { center: r?.position }
            button "Stop" { on click { fleet_client.stop(id)? } }
        }
    }
}

fn robot_row(r: RobotState) -> dyn View {
    row {
        text "#${r.id}"
        text "${r.picked} kg"
        text r.status.word()
    }
}


// ══ 10. THE VOICE — an agent with the program's own verbs ════════════

agent support {
    model: "claude-sonnet-5"
    instructions: "You help growers run the Orchard fleet. Be brief. Never move a robot without asking."
    tool today                                             // the api's fns ARE the tools:
    tool robot                                             // their types become the schema,
    tool stop { approval: required }                       // their laws its guarantees
}


// ══ 11. THE MACHINES — the deploy is a projection of the program ═════

deploy production {
    region: "eu-west"
    fleet robots {
        runs: every                                      // the control loop, on 40 Jetsons
        hardware: "jetson-orin"
        count: 40
    }
    service api { runs: orchard, replicas: 3 }
    database main { engine: sqlite_replicated, size: 20 GB }
    service teacher { runs: ripeness, on: "gpu-pool", schedule: "every night at 02:00" }
    secret push_key
    budget { heap: 512 MB, p99: 50 ms }
    reach { Pure, Db, Net }                              // no process, no clock outside `every`
}

deploy staging from production {
    region: "eu-west-stage"
    fleet robots { count: 2 }
}


// ══ 12. THE TOOLS — the operator's CLI, from the same types ══════════

cli orchard_ctl {
    description: "Operate the Orchard fleet"
    command stop {
        arg robot { required: true }
        flag all { short: "-a" }
        run {
            if self.flags.all { fleet.stop_all() } else { fleet.stop(RobotId(self.args.robot)) }
        }
    }
    command replay {
        arg day { required: true }
        run { replay_day(self.args.day) }                // yesterday, bit for bit
    }
}


// ══ 13. THE PROOF — tests the scheduler explores, on virtual time ════

@derive(failure_tests)                                   // one test per way `control` can fail:
fn control_survives() { control() }                      // each injected at its source, each asserted handled

spec "orchard" {
    given "a person walks into a row" {
        then "every arm in the row slows within one tick" {
            let world = simulated(robots: 8, people: [walking(row: 3, at: secs(1))])
            world.run(secs(3))
            world.arms(row: 3).all(it.max_speed_after(secs(1) + ms(10)) <= 0.5)
        }
    }
    given "the cluster loses a node mid-epoch" {
        then "training finishes with the same weights" {
            let clean = train_sim(ripeness, nodes: 4)
            let hurt = train_sim(ripeness, nodes: 4, kill: node(2, at: epoch(7)))
            clean.weights == hurt.weights                // fixed trees, durable steps
        }
    }
}


// ══ 14. THE WALL — C, crossed once, honestly ═════════════════════════
// packages/fleet-arm: the vendor's libarm.so behind one checked door.

extern fn arm_read_joints(out: ptr, n: i32) -> i32       // C's widths, said at the seam
extern fn arm_command(joints: ptr, n: i32, speed: f32) -> i32
```

## What the compiler refuses

The best part of the tour is the part that does not compile.

**Somebody raises the speed cap.**

```avra
let cap: Meters = if nearest < 2.0 { 0.8 } else { 1.5 }
```
```
error[L0001]: law `gentle_near_people` fails
  counterexample (shrunk): nearest = 1.9, pose.speed = 0.8
    commanded(pose, 1.9).speed = 0.8, and the law wants ≤ 0.5
  --> orchard.av:112
help: the law is the grower's; change it there, or change the cap
```

**Somebody logs inside the control loop.**

```avra
fn control() {
    log.info("tick ${n}")
```
```
error[F2141]: `control` allocates, and its budget is `heap: 0`
  --> orchard.av:93   `"tick ${n}"` builds a string: 1 allocation per tick
help: count ticks into a field, and report from `on late` or another task
```

**Somebody deletes a catch arm from the control loop.**

```avra
arm.command(commanded(pose, nearest), verdict) catch {
    .Stalled(j) -> arm.release(j)
    .Overcurrent(_) -> arm.brake()
}
```
```
error[F1213]: `control` is total, and `arm.command` can fail with `ArmError.Unreachable`
  --> orchard.av:170
  = because: `Unreachable` was added to `ArmError` at fleet/arm.av:14 (last commit)
help: add the arm — `.Unreachable(_) -> arm.home()` — or let `control` answer a Result
```

One new variant five layers down lights up every boundary it can
reach, as a worklist, before anything ships.

**Somebody feeds the wrong image in.**

```avra
let p = classify(weights(), thumbnail)     // a Tensor<float, [3, 112, 112]>
```
```
error[F2120]: shapes disagree — `classify` wants [3, 224, 224], this is [3, 112, 112]
help: `resize(thumbnail, [224, 224])`
```

**Somebody makes the agent reckless.**

```avra
tool stop                                   // `approval: required` removed
```
```
warning[@std/ai: A2]: `stop` writes the world (fleet.send) and the agent may call it unasked
help: `tool stop { approval: required }`, or mark the fn `@safe_for_agents` and say why
```

**Somebody ships a node the cluster can't trust.**

```avra
step(w, batch) { classify_grad(w, batch.frames, loss: loss_with(db)) }
```
```
error[F2130]: a task sent to another machine captures `db`, which holds a local handle
help: send the rows the step needs, never the connection
```

Every one names what is wrong, where, and what to do. None says
"internal error". That is the whole bar.

## Why one language

Look back at the program and count the boundaries that aren't there.

- **The robot and the server share a type.** `RobotState` crosses HTTP,
  the database, the app and the agent's schema. It is declared once,
  and a change to it is a compile error everywhere it breaks, today, not
  a 3 a.m. page when the phone app deserialises a field that moved.
- **The model and the robot share a function.** `classify` is trained on
  the cluster and run on the Jetson. It is the same code. There is no
  export, no ONNX, no second implementation drifting from the first.
- **The law and the code share a compiler.** `gentle_near_people` isn't
  a comment or a ticket. It is checked on every build, and the fleet's
  deploy refuses a binary without the receipt.
- **The deploy and the program share a source.** The fleet size, the GPU
  pool, the budget and the reach are declarations the compiler reads,
  checks and projects. A service that reaches the network without
  declaring `Net` doesn't deploy.
- **The failure and the fix share a type.** `ArmError.Unreachable` is a
  value with a kind, a message and a place it came from. Every catch
  that can receive it is known, the loop that must never fail is
  proven total, and a new variant lights up every boundary it reaches.
  A robot doesn't discover a new failure in a row at night.
- **The agent and the API share the verbs.** The agent's tools are the
  API's functions. Their types are its schema, their laws its
  guarantees, their `@auth` its permissions. Nothing is described
  twice.

The thesis of Avra is that the compiler should hold the knowledge no
other tool has (P10), and that everything else, the docs, the clients,
the schemas, the manifests, the dashboards, should be a projection of
one source of truth (P12). Orchard is what that looks like when it is
finished.
