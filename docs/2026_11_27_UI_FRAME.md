# The UI frame — one binary format for every wall (proposal)

**Ask:** the neutral frame (a realized tree and its patches, crossing a wall) is ONE binary format,
generated from the tables the web's wire already reads. For the page, dev tools, record and replay,
and storyboard parity. iOS in one process keeps calling its host directly, with no encoding.

## The tables it reads (nothing new is spelled twice)

| Fact | One definition today | Read by the frame as |
|---|---|---|
| An op's number | `Op` (`realize/dom/wire.av`, `@derive(Codes)`) | the web vocabulary, unchanged |
| A native patch | `NativePatch` (`realize/native/patch.av`) | the neutral vocabulary: `NeutralOp`, `@derive(Codes)`, one arm per variant |
| A fact's code | `What` (`native/fact.av`, `@derive(Codes)`) | `Code` |
| A prim, an interaction | `Prim`, `Interaction` (`@derive(Words)`: `ordinal`, `every`) | `Code` |
| A seat | `Seat.number()` / `seat_numbered` | `Code` |
| An id, a place's `after` | `push_id`, `push_after` + `Kept` (`wire.av`) | `Id`, `After`, moved to the shared module as they are |
| Bytes | `Buf` (`dom/buf.av`) | the one writer, plus a `Reader` beside it |
| The host's copy | `host_table` → `wire.gen.js`, `make ui-host` | the same generator, emitting the neutral rows and the reader |

The new module is `realize/frame/`. It holds the **field kinds**, one spelling each: `Id` (varint of
n+1, so 0 is none), `After` (0 first, 1 the end of a run this frame built, n+2 a sibling), `Code`
(varint), `Count` (varint arity, then that many), `Text` (varint byte length, then the bytes), and
`Scalar` (one tag byte from `Scalar`'s own table, then text, nothing (a flag is two tags), a zigzag
varint, or 8 bytes of float bits). A vocabulary is a `Codes` enum of ops plus one exhaustive
`fields(op) -> List<FieldKind>` registry. The encoder, the Avra reader, the schema rows and the JS
reader are all projections of that registry. The JS reader is generated source, one function per op,
so it is not an interpreter loop.

## Layout

- **A frame** (one paint) is a `Dialect` byte, then records: an op byte, then its fields in registry order.
  A frame of the dialect byte alone is a paint that changed nothing. A first paint is a diff against
  nothing, so **a realized tree is the frame that draws it from nothing**: no second tree encoding.
- **A tape** (record and replay, dev tools, a storyboard snapshot) is a header and then entries. The
  header is magic, the tape version, the dialect, and the schema rows (each op's word, code and field
  kinds). Each entry is a kind (`Frame`, `Echo`, `Measure`), a `Count` length, then its bytes. The
  boundaries are recorded: two paints are never one paint of their union.

## Versioning (the meta boundary's rule)

- `Dialect` is ONE `@derive(Codes)` enum, `dom_15`, `neutral_1`, and so on. Every vocabulary and version is
  a code in one space, so a web frame given to a neutral reader is refused, and the derive refuses a
  reused number. A reader refuses a frame **by name**: "this frame is `neutral_2`; this reader reads
  `neutral_1`".
- **Growth is not a move.** A new op, or a field appended at a record's end, keeps the dialect. A tape's
  reader takes the slots it knows by slot order and skips the rest by the header's kinds. A **move**
  (a field renamed, reordered or dropped, or a code reused) needs a new dialect. The keeper is a
  checked-in copy of the schema rows: a test refuses a moved known slot under an unchanged dialect,
  naming the op and the slot. Live walls (the page) are built with their host, so a mismatch there is
  only ever a stale cache, and it is refused.

## Encoding laws, written as tests before the encoder

These colliding pairs must differ in bytes:

- `Place(a, null, _)` vs `Place(a, NodeId{-1}, _)`. A negative id traps at the encoder; it is never read as "none".
- `Text("")` vs `Flag(false)` vs a dropped fact.
- `under` none vs `Hover`.
- `Number(n)` vs `Fraction` with the same bits.
- An empty `Count` vs one empty text.
- Tape `[f1][f2]` vs `[f1++f2]`.
- Tape `frame, echo, frame` vs `frame, frame, echo`.
- A `dom` frame vs a `neutral` frame with the same body.

The empty case is written first in each (an empty frame, an empty tape, an empty text, zero facts).

## Witnesses

1. **Round trip against the SOURCE:** `read(write(ps)) == ps`, compared field by field with the
   `NativePatch` values the diff made, never by re-encoding. Over the board at 0, 1, 100 and 1,000 rows,
   and over every story's first paint.
2. **eval == native:** a program test (`realize/frame/tests/<name>/`), with `.expected`.
3. **A mutant that drops a field fails:** a test-only writer skips slot *k* of op *o*, for EVERY (op, slot)
   in the registry, and each one must fail the round trip or be refused. Exhaustive, not sampled.
4. **Record, replay, identical frames:** the board on a headless native page records a session's
   frames and echoes. A fresh program fed the tape's echoes yields byte-identical frames. eval == native.

## Probes run (HEAD `13c2fd4`, the gate's landed compiler; dev build, linux x86; scratch package over `@ui/board`)

| The board, first paint | Web wire (v15) | Prototype neutral frame |
|---|---|---|
| 100 rows: records / bytes | 2,707 / 43,861 B (4,600 of them the sheet) | 1,453 / 11,748 B |
| 1,000 rows: records / bytes | 25,207 / 374,167 B | 13,153 / 112,551 B |
| Encode, 1,000 rows (Avra, mean of 20) | 9.5 ms | 2.1 ms |
| Decode, 1,000 rows (node 22, mean of 100) | 3.3 ms (`parseFrame`) | 1.1 ms |
| One row toggled | 116 B | 60 B (5 patches) |

- The web's own 4-byte lengths and numbers, written as varints instead, measure 18–19% smaller
  (35.9 KB / 301 KB). That is the one place the web spells a fact differently from the neutral frame.
- A derive can read a variant's payload: `Variant.fields` carries each field's name and kind, and
  `@derive(Fingerprint)` already reads it. So the registry could be generated from the enum itself.

## Asks for a ruling

1. **The web moves onto the shared kinds** (varint text and numbers) as `dom_16` in this lane. That makes
   one spelling of a text, and the web is 18% smaller. Its goldens change once. Or keep `dom_15` byte-identical
   and let the web's `Int` stand as a second spelling until a later slice.
2. **The registry:** hand-written `fields(op)`, exhaustive, with every consumer projected from it (this
   lane). Or `@derive(Frame)` on `NativePatch` reading `Variant.fields` (larger, and the web's stateful
   `After` and `Define` need a codec seam).
3. `realize/dom/snapshot.av` (a third hand-written format, 4-byte ids) becomes a tape's first frame in a
   follow-on slice, not this one.
