# INPUTS — a handler's input is one record

Decided by the owner 2026-11-27. Ticket `avra-8sb5.98.22`.

```avra
@Input
type NewIdea = {
    @path board: string
    @body draft: IdeaDraft
    @query page: Page
}

post "/boards/{board}/ideas" { i: NewIdea -> created(save(i.board, i.draft, i.page)) }
```

## 1. What a request answers

- Every field reads from the one source its mark names: `@path` a capture, `@body` the body, a form or JSON by its content type, `@query` the query (`query<T>`).
- One refusal: every source is read, every issue kept, and one 422 lists them all, each with its `in`.
- A capture or query that is not text is a 400, as today (`captured`, `query<T>`).
- A field with no mark is refused at the declaration (`input_unsourced`), at the field.
- Rules on the input's own fields (`@path @range(1, 99) board: int`) are std-validate's, judged after every part reads, each issue in its field's part. They run once every part has decoded: a part that fails to decode hides them (`board=700` beside `limit=500` names only `limit`) — owed.

## 2. The parts

| Part | Where | What |
|---|---|---|
| `@path`, `@body`, `@query` | std-http | markers, as `@secret` is in std-validate |
| `@Input` (trait `Input`'s derive) | std-http | answers `Declared`: generates `Input.read` and std-validate's `Checked`, and refuses a field naming no part |
| `Captures` | std-http | a route's holes by name: `fn at(name: string) -> string?` |
| a format record answers its holes by name | compiler (`item_formats`) | the record a pattern mints implements `Captures`; general to every format, not keyed to HTTP |
| a route handler typed `{ i: T -> … }` | std-http route components | `T: Input` reads `i` before the body runs |
| `@path x` names a hole, every hole has a field | compiler, at the route | waits on `.132` |

## 3. Order

1. `Input`, the marks and the derive, read through `req.input<T>(captures)`. Witness: every source bad at once, one 422.
2. The format record answers its holes by name (a compiler slice, generalized).
3. Routes take `{ i: T -> … }`.
4. The route law (after `.132`).
5. std-openapi reads `T`.

## 4. Open

- `@body` follows the content type (built so); a separate `@form` is the alternative, owner to confirm.
