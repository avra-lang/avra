# The diagnostics index

GENERATED by `avra diagnostics` from the assembled registry —
`make witnesses` refuses an index the compiler did not make. Each
entry's rendering is the compiler's own words over the witness
beside it, so a voice whose wording drifts shows up here as a diff.
Its totals are `avra diagnostics`' own line on stderr, never this file's.
