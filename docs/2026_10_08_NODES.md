# A node is one declaration

Status: owner-approved design. Epic: avra-8sb5.89. Every rule names the node it
builds; one hand builder stands — `build_sublang`, the sublanguage registry lookup,
the agreed escape hatch.

## The law

A syntax node is declared ONCE, in its feature's directory. Its shape, its surface syntax,
its meaning and its examples live with it. Everything derivable from the shape is derived.
Core holds no per-node knowledge and imports no feature.

## Where it ends: one feature, end to end

```avra
@expr_node
type When = { conds: List<ExprId>, values: List<ExprId>, fallback: ExprId }

const syntax = grammar {
    primary = "when" "{"
        ( BREAK | "," | "_" "->" fallback:expression | conds:expression "->" values:expression )*
        "}" @expect("}", "expected `}` to close the `when`") -> When
}

impl Meaning for When {
    fn means() -> Code? { ladder(self.conds, self.values, self.fallback) }
}
```

- The grammar block's `-> When` names the record a rule builds: its labels ARE the record's
  fields, so the builder is derived and the printer reads the same rule.
- `means()` makes a node SUGAR: a rewrite into other nodes, built with `quote`. Its type,
  lowering and diagnostics follow from the rewrite.
- No new syntax: the grammar block, `quote`, traits and gathered enums already exist.

## The road (each step deletes code)

1. **`collect enum E: T`**: a gathered enum implements `T` by delegating each method to the
   member's own impl (`.V as r -> r.m(…)`); a member without the impl is refused where it is
   declared. (#435 `.V as r`, #439.)
2. **A node's meaning is its record's `impl Meaning`** (`resolve`, `type_of`, `lower`).
   `Expr` lives in core and `Meaning` names features' contexts, so the trait says which enum
   it is delegated over: `@delegates(Expr)`, `@std/meta`'s `delegates`. `semantics_of`'s
   expression half is deleted; `kids`/`heirs` are the traits `Kids`/`Heirs`, derived per member (step 3). A
   follow-up rewrites the moved bodies to read `self`'s fields instead of re-matching.
3. **Shape-reading defaults**: `kids` (`collect enum Expr: Kids`: a member with no impl answers its
   expression fields) and `heirs` (a member with no impl takes the default `[]`) landed; the derives that walk fields (Children,
   Rebuild, Identity, Exact, Matchable, Fingerprint) become defaults read off the record's shape.
   Open: those six are still derives (`core/*_derive.av`); whether a field-walking default
   replaces them waits on the owner's marks-vs-overrides decision.
4. **Stable node identity**: rule shapes key a node by its NAME, never its position (#448).
   Landing 3 deletes the `@…_node(i)` ranks: a node kind is keyed by its name, order is free.
5. **Grammar `-> Record`**: the rule's labels fill the record; `builders.av` and the
   per-node printer arms go. The rule labels, the record declares, the checker refuses:

   ```avra
   @stmt_node
   type FnDecl = {
       name: Scoped,
       params: List<Param>,             // a repeated group builds its own small record
       ret: TypeRef? = null,            // a default when the label is absent
       body: StmtId,
       @facet exported: bool = false,   // kept in a side table, never on the node
   }
   stmt = ( exported:"export" )? "fn" name:NAME "(" params:param* ")" ( "->" ret:type )? body:block -> Stmt.FnDecl
   ```

   What a builder once did by hand, each class now says declaratively:

   | a builder… | now |
   |---|---|
   | read labels into a record | the maker derive (`@derive(Makes)`), `-> Stmt.X` / `-> Record.X` |
   | filled a default | `Field.default`, read where the label is absent; `@hollow` for a body a rule may omit |
   | wrote a side table | a `@facet` field, marked when its label is written |
   | placed a node at a label | `@anchor` |
   | re-aligned flat captures | a nested group record its own rule makes (`FieldPat`, `CatchArm`, `ProjField`, `OrderKey`) |
   | chose a node from what arrived | grammar branches each ending `-> Variant` (below); terminals by form (`RAW_STRING`, `FRACTION`, `INTEGER`) |
   | checked a contextual word | a feature's `soft_words`: matched where written, never reserved |
   | refused a shape | a typing, resolve or grammar law (`-> Refusal.x`) with its own kind |
   | folded an operator run | `@fold(field)` / `@operators` |
   | desugared | `means()` / `minted`, or a computed node (`-> Node by fn`, an `@computed` fn) |

### 5b. The printer reads the rule

The same bound rule that builds a node prints it. At assembly (`node_wordings`,
features/node_print.av) each branch that builds a node from its labels is read
once into a `Wording`: the words it writes, one hole per payload it names (an
expression at the tier of the rule the hole names, a name, a written type), and
an optional group around one hole. The formatter fills the wording from the
node's `Surface` (`@derive(Surfaced)`: its name and one `Fill` per carried
payload, by position) — a printer arm for such a node is not written.

```avra
unary = "!" value:unary -> Expr.Not
primary = "channel" "<" elem:type ","? ">" "(" ( cap:expression )? ")" -> Expr.Channel
```

| What the rule writes | What the printer does |
|---|---|
| a word | the word |
| `label:rule` over an expression payload | the payload at the tier `rule` ranks (`rule_scale`) |
| `label:NAME` / `label:type` | the name / the written type |
| `( label:rule )?` | the group, when the payload is present |
| `","?` (an optional word) | nothing: the canonical form leaves it out |
| `END` | nothing: the line owns its terminator |

- **Spacing is the printer's, never the grammar's.** Two words or holes that meet
  are kept apart by a space; a mark with a `Layout` row (`( ) < > . .. ! = :`) sits as its row says.
  A rule writing any other mark (`->`, `=`, `{`), a repeated group, a captured
  literal, a stated payload, a climb, or a space that would depend on whether
  an optional group is printed has no wording, and its node keeps its own arm.
  Found by the receipt: `.Dot as d` printed `.Dotasd` before spacing existed.
- **One scale, checked.** A hole's tier is the rank of the rule it names, listed
  in `rule_scale` beside the printer's tier constants. A hole naming an unranked
  rule leaves its node without a wording.
- **Claimed, never silent.** `worded_nodes` lists the nodes the printer reads
  from their rule; assembly refuses a claimed node whose rules do not read as one
  wording, so a rule edited out of the shape fails the build, not the output.
- **One assembly.** The wordings are a field of `Language`, built once with the
  grammar; the formatter reads them through `avra()`.
- Out of scope, by step: operator folds and repeated groups (width-wrapped lists)
  stay hand-printed; a node that desugars in its builder (`spawn`, `defer`,
  `within`) must keep its written form to round-trip, which is step 6's `means()`.

6. **Sugar by `means()`**: a node's `means()` is the template it expands to, `minted` the
   meaning computed from what stands around it, and a refusal is the sugar's `.Err`, spoken
   where it stands. A sugar's own check and lower bodies go once its meaning carries them.

### 6b. The hatch

`build_sublang` reads the sublanguage registry at the parse — the grammar a block
word names is chosen by what the file imports, which no rule can state. It is the
one hand builder, and a new one is a defect to name here first.

**Choice → branches.** A builder that picks a node from what arrived is two
branches of one rule, each ending `-> Variant`, the last alone recovering: a
sub-rule's failure falls through to the expression floor and speaks there, so
`impl` is two `stmt` branches on its keyword, the `for` form first. A captured keyword fills a `@facet` flag
(`statement:"if" … -> Expr.If`), and a facet's captured word is no part of a
template — the printer that reads the side table says it (`${..name}` is
`run:".." name:NAME -> Expr.Ident`).

## Laws kept

- Registry law: no silent default. A member's impl is written, or the build refuses.
- Core never imports a feature; dispatch is generated, never hand-written.
- Every step lands green on its own and deletes the code it replaces.
