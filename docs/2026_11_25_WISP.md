**Base:** `origin/program` at `94c02115` (train49). **Epic:** `avra-8sb5.100`; settings `.104.6`.
Counts: [WISP_INVENTORY](2026_11_25_WISP_INVENTORY.md).

> **`avra` is the language's CLI; `wisp` is the repo's.** Every check, ratchet, measurement and
> lane mechanic is one wisp verb, in Avra on `@std/cli`, typed flags, deterministic unless a flag
> says otherwise. Make keeps only what builds a file.

## 2. The verb tree

| Verb | Holds |
|---|---|
| `wisp gate [--changed\|--slice <s>\|--full]` | the PR check, the slice gate, the whole gate: one row list |
| `wisp keepers [<name>…] [--set <s>] [--list]` | every keeper as a registry row (name, set, needs-compiler, run) |
| `wisp oracle [<case>…]` | the declarative agreement cases (§5) |
| `wisp cost [<ratchet>] [--accept]` | every ratchet over a committed baseline; each `-accept` target is `--accept` |
| `wisp census <what>` | reports with no verdict: census, tapes, settled, repr, grammar, sizes, bench |
| `wisp seed [check\|refresh\|ladder]` | the seed and the generation ladder |
| `wisp idioms`, `wisp voices` | the idiom and voice ratchets, `--accept` |
| `wisp fixtures` | every instrument's self-test, beside a verb, never inside it |
| `wisp tree <…>` | facts about the tree, read through the compiler's own readers (`tree_settings` today) |
| `wisp work <…>` | the lane mechanics; the Sprite half dies with it |
| `wisp preflight` | a lane's own pre-gate run |

`avra` keeps the user's commands: check, build, run, test, fmt, fix, docs, explain, dev, expand,
ir, emit, process, tasks, trace, db, cache.

## 3. Built and found

- **Package** `packages/wisp`, `[bin] wisp`; held by idioms and fmt like any package, and its
  tests run in the derived suites.
- **Shim** `./wisp [--key|--path|--compiler <avra>] <command> …`. The binary is
  `build/wisp/<key>/wisp`, else the asset published for the key, else a build here.
  **A keeper is never judged by the compiler under test:** the shim builds with main's
  compiler, or, in a program tree, takes the wisp published beside the gate's builder.
- **Make calls wisp; wisp calls Make only for files.** `bootstrap`, `avra`, `try`, `install`,
  `clean` and the object rules stay in Make: they run before a compiler exists.

## 4. Flags, not env

| Today | Becomes |
|---|---|
| names only tools read (`AVRA_LADDER_*`, `AVRA_LAND_*`…) | typed flags of their verb (`@std/config`, `flags argv()`) |
| compiler switches (`*_OFF`, `*_CHECK`…) | `settings.debug` in the one declaration; landed train44, an oracle reading sets them |
| user-facing (store sizes, `AVRA_CACHE_DIR`, `AVRA_HASH_SEED`…) | kept, typed by the same declaration; C reads generated `AVRA_SET_*` names |
| shim names (`AVRA_CWD`, `AVRA_BIN`…) | argv between `./avra` and the binary |
| `AVRA_TOOLS_COMPILER` | `./wisp --compiler`; read one more train as a deprecated alias |

Every child wisp spawns gets an `Env.Only` from its declared settings; `--inherit-env` is the
visible hatch (P8). Every child runs capped and bounded through one runner.

## 5. The oracle format (S3)

Every "two readings agree" proof is one `Case`: data in `packages/wisp/src/commands/oracle_cases.av`.

```avra
Case {
    name: "width-witness",
    subject: "packages/width-witness",
    needs: ["build/width_witness.o"],
    readings: [
        Reading { name: "native", how: How.Native },
        Reading { name: "c", how: How.Reference([["cc", …], ["build/witness-c"]]) },
    ],
}
```

Spec-harness's eight conditions, each in the shape: readings name their store and order
(`Store.Fresh`/`After(i)`); masks live in the case; every reading is `{ stdout, stderr, exit }`;
`standing: Holds | Differs(why) | Alone(why)`; all-Avra readings with no golden are refused; one
planted disagreement per kind; attacks and scenario witnesses stay programs; gated readings set
`settings.debug`.
