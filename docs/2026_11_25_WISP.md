# WISP — the repo's one internal CLI

**Status:** DESIGN, for the lead's ruling. Nothing is built.
**Epic:** `avra-8sb5.100` (.100.1 is the inventory, .100.2 the oracle format). Settings: `.104.6`.
**Base read:** `origin/program` at `d7cd84d9`. Counts: [WISP_INVENTORY](2026_11_25_WISP_INVENTORY.md).

> **`avra` is the language's CLI, and `wisp` is the repo's.** Every check, ratchet, measurement
> and lane mechanic is one wisp verb, written in Avra on `@std/cli`. It takes typed flags,
> and it is deterministic unless a flag says otherwise. Make keeps only what builds a file.

## 1. What it replaces (measured, §Counts of the inventory)

160 Make targets, 299 `tools/` entries, 270 `AVRA_*` tokens (73 of them no setting) and 42 cli
files. Of these, 138 targets, 277 tools entries, 150 names and 18 commands merge into wisp.
28 are deleted outright. **Wisp is not new code.** `tools/avra.toml` + `tools/src/` (`avra-tools`)
is already an Avra `@std/cli` program with six commands, built by main's compiler and published
by key. Wisp is that package, renamed.

dev, expand, ir, emit, process, tasks, trace, db, cache.

## 3. Built and found

- **Package:** `packages/wisp` (moved from `tools/`) with `[bin] name = "wisp"`. It sits in
  `packages/`, so `make idioms` and fmt hold it like any package.
- **Shim:** `./wisp` at the root replaces `tools/avra_tools.sh`. Its resolution is kept: the
  binary under `build/wisp/<key>/`, else the published asset for the key, else a build here.
  **A keeper is never judged by the compiler under test,** so wisp is built by *main's*
  compiler, not by the standing one (that is `avra_tools.sh`'s law today).
- **Make calls wisp. Wisp calls Make only for files.** A target that is a verdict becomes
  `target: ; @./wisp keepers <name>` for one transition, then dies (§6). CI calls `./wisp gate …`.
- **The cold tree:** `bootstrap`, `avra`, `try`, `install`, `clean` and the object rules stay
  in Make, because they run before any compiler exists to build wisp.

## 4. Flags, not env

| Today | Becomes |
|---|---|
| 75 names read by tools alone (`AVRA_LADDER_*`, `AVRA_LAND_*`, `AVRA_WAIT_*`…) | typed flags of their verb. A verb's flags are an `@std/config` component, with `flags argv()` as their only source |
| 68 switches the compiler reads (`*_OFF`, `*_CHECK`, `AVRA_FOLD_*`, `AVRA_HELD_*`…) | `settings.debug`, a nested record of the compiler's **one** typed settings declaration (`.104.6`). Wisp sets it per oracle reading |
| 44 user-facing (store sizes, `AVRA_CACHE_DIR`, the runtime's `AVRA_HASH_SEED`, `AVRA_MEM_STATS`…) | kept, typed by the same declaration. The runtime's C reads them in constructors, under names generated from it (CONFIG §9) |
| 8 shim names (`AVRA_CWD`, `AVRA_LIGHT`, `AVRA_BIN`…) | argv between `./avra` and the binary |
| `AVRA_PROGRAM`, `AVRA_PROGRAM_NET`, `AVRA_ALIAS_EMIT` | deleted: nothing reads them |

**Deterministic by default:** every child wisp spawns gets an `Env.Only` built from its declared
settings. Nothing ambient leaks into a verdict, and `--inherit-env` is the visible escape hatch (P8).
Every child also runs capped and bounded through one runner (`watch.sh`, `memcap.sh` and `capped.sh` merge).

## 5. The oracle format (.100.2)

Every proof that "two readings agree" or "this reading is refused" becomes **one case shape**:

```avra
oracle held_items_cut {
    subject: Subject.Package("packages/cli")
    readings: [Reading.Cold, Reading.Warm, Reading.Gated(Switch.HeldItems)]
    agree: Facet.Diagnostics
}
oracle extern_wrong_box {
    subject: Subject.File("cases/extern_box.av")
    readings: [Reading.Eval, Reading.Native]
    expect: Expect.Refuses(code: "F2084", golden: "extern_box.refuses")
}
```

- **Readings** are an enum, spelled in full by every consumer: `Cold`, `Warm(edit)`, `Eval`,
  `Native`, `Gated(Switch)`, `Ungated`, `Seed`, `Standing`. A `Switch` is a `settings.debug` field,
  never a string.
- **Facets** say what is compared: diagnostics, stdout, exit status, IR, or the store's digests.
- **The runner** runs every reading and compares the facet. It prints the first line that
  differs, with both readings named. Agreement is not truth, so a case may also name a golden.
- `avra test`'s `.expected`/`.refuses`/`.verdict` markers are already the `{Eval, Native}` case.
  They stay, and they read as oracle cases.

## 6. Migration order (one path at a time; the old one dies in the same change)

1. **Rename** `avra-tools` to wisp, `tools/` to `packages/wisp`, and `avra_tools.sh` to `./wisp`.
   Its six commands keep working.
2. **`wisp tree objects`**: the first verb. It answers from the compiler's `host/manifest.av`, so
   the awk copy dies. The cold tree needs the list before wisp exists, so wisp writes it as
   `bootstrap/objects.mk` (committed, `include`d by Make), and `wisp tree objects --check`
   holds it fresh, just as the seed is held.
3. **`wisp keepers`**: the registry. Each keeper target moves in turn and its Make line goes.
4. **`wisp gate`**: CI switches to it. `gate.sh` and `gate_changed.sh` die.
5. **`wisp oracle`**: the case table. Each witness or attack script dies as its case lands.
6. `cost` with `--accept` (the 16 `-accept` targets die), then `census` (the internal `avra`
   commands leave the user CLI), then `seed`, `idioms`, `voices` and `fixtures`.
7. **`wisp work`**, last, because it is the lanes' own tool. The Sprite code dies with it.
8. **Settings** (`.104.6`): this needs `@std/config` C4's `@env("AVRA_X")` exact-name override,
   or the user-facing names change once.

Every step prints the inventory row it closed. A row that is still open is a path not yet deleted.
