## 1. The pipeline

```
source ─ parse ─ items ─ namespace ─ resolve ─ sig ─ typed ─ analysis     per FILE / per DECL
                                                     │
                       settle (consts) · lift (annotations) · expand       compile time, in the evaluator
                                                     │
                                  lower (units) ─ memory ─ Lowered         per BODY, per instantiation
                                                     │
        check: what was said     run: the evaluator     build/test: objects ─ link
```

Every stage is a QUERY in the memo kernel (`query/db.av`): keyed, memoized, its
dependencies recorded. `Family` (`compiler/workspace.av`) lists them in order.
Across runs nothing of the kernel survives; what survives is the STORE, and the
DERIVATION decides what it may stand in for.

| stage | family | key | module | answers |
|---|---|---|---|---|
| read | `Source` | file | `workspace.av`, `host/` | `SourceFile`: text, line starts |
| parse | `Parsed`, `Plain` | file | `program.av`, `grammar/` | the AST (`NodeStore`), spans in side tables |
| items | `Items` | file | `features/decls_mint.av` | the declarations a file MINTS |
| names | `Namespace`, `Visible` | module, file | `features/namespace.av` | what a module binds, what a file sees |
| expand | `Expanded`, `Lifted` | file, annotation call | `expand.av` | generated declarations; a lifted call's answer |
| resolve | `Resolved` | file | `resolve/` | `NameFacts`: names → bindings |
| signature | `Sig`, `Methods`, `ConstTyped` | declaration | `typing/declare.av`, `typing/impls.av` | a declaration's types; a type's methods |
| typing | `Typed`, `Folded` | declaration, file | `typing/` | `TypeFacts` over one declaration |
| analysis | `Analysis` | file | `analysis.av` | every fact of one file, in ONE value |
| receivers | `Receivers` | program | `receivers.av` | which seats are written |
| settle | `Settled` | const / expr + seats | `backend/interp.av` | a const's value, run at compile time |
| lower | `Lowered` | unit (decl, type args, seats) | `lower/` | bodies of IR, the units it wants |
| memory | — | `Lowered` | `memory/` | retains, releases, scopes placed |
| emit | — | file / program | `backend/llvm*.av` | one LLVM module per file, one for the program |

A pass is `pass(p: Parsed, ...upstream Facts) -> Facts` and OWNS its fact
tables. A feature's rule is reached through `semantics_of` /
`stmt_semantics_of`; a pass never matches a feature's node.

## 2. The derivation and the store

`Workspace.derived(entry, want)` (`compiler/derive.av`) is the ONE verb `build`,
`check` and `test` ask. It reads as its phases — `holding`, `admit_all`,
`analysed`, `bodies_lowered`, `kept`, `stood` — over one `Attempt` value; "ask
again" rides the failure channel as a `Turn` (`Again(Attempt)` / `Refused`).

1. **hold** — per file: is its text the text its module's record was written
   from, and does the store hold what stands in for it under this `want`?
2. **load · admit** — a read file's declarations from its parse; a held module's
   are minted from its record the first time anything reads them (`mint_module`).
   `whole.av` skips held files in both the parse loop and `admit_all`.
3. **analyse** — §1's stages, for read files only.
4. **lower** — every body of every read file, each file's top level under its
   program symbol. Instantiations whose generic's file is held are OWED
   (`unlowered`), not lowered.
5. **keep** — records, what each file said and asks, settled consts.

A failure under a hold is asked again of the sources; only that answer is the
program's. `check` prints `Derived.warnings`; `build` links (`build.av`);
`test` is a build whose entry calls every case and program test (`suite.av`).
`run`, `emit`, `ir` still lower with nothing held — the evaluator reads IR and a
held file has none (§7, S8).

**The model, as eight laws:**

1. **A file's object is the FILE's** — every plain body it declares, so no
   program's reach shapes it. Two programs sharing a store share it.
2. **An instantiation is the PROGRAM's** — owned by no file, weak, riding the
   program's module, which is keyed by its own bitcode bytes (`bytes_keyed`).
3. **What stands in for a held file is ONE key's worth**: its object, its asks,
   and record lines that say what text they were read from. All three, or it parses.
4. **A generic's home is never held** while an instantiation is owed from it.
5. **A restart is a NEW workspace** (`anew`): a copy shares its tables. **And
   the one before is let go first** (`discarded`): every attempt runs in a
   workspace of its own, and one that turned, owes (`derived_owing`) or
   quarrelled gives back what it derived before the next begins — a build's
   peak is its largest attempt, never their sum (`make turn-memory-attack`).
6. **The sources are the hold's oracle.** A hold bug costs time, never a wrong
   answer. A trap still escapes it.
7. **A layout is ONE law's answer, and it is in the interface** (`Decls.declare`
   from source and record alike; a sealed flat record's line says `boxed`).
8. **A file's key folds what its bodies can SEE**: its text, its own module's
   interface, the closure of its imports, the texts its compile-time runs read.

**What is kept, and under what:**

| row | family | key folds |
|---|---|---|
| a module's record | `Sig` | the root, the module's NAME |
| a file's object, what it said, what it asks | `Obj`, `Warn`, `Unit` | law 8 |
| the program's module | `Obj` | its bytes; and its inputs: root asks, homes' keys, the entry |
| a settled const | `Unit` | its file's key, its name |
| "these instantiations lowered clean" | `Unit` | the program's asks |
| a program the evaluator agreed with | `Unit` | the text it must print, every text it can reach |
| the binary, a suite's binary, `check`'s verdict | `Bin`, `Warn` | path, length, digest of every input in the closure its last derivation admitted |
| a program's closure | `Unit` | the root, the program's name |
| the tree's stamps | `Fp` | one row: path → stamp, digest |

**A store is ONE compiler's**: `.avra-cache/<print>/`, the print the running
binary's bytes (`compiler_print`), the newest four kept on
`.avra-cache/compilers`. Adopting a compiler costs one cold build; a user pays
nothing. **An object is made ONE way**: in process (`emit_object`, four
workers, each module its own LLVMContext); clang only links. A refusal is never kept.

**A light run skips the watchdog**: the `avra` shim tries `AVRA_LIGHT=1` for
`check|build`; the compiler leaves with status 75 (`TOO_HEAVY`) when the hold
is thin (`Host.reads_ahead`, `LIGHT_READS`), and only then does the shim queue
on `tools/watch.sh`.

## 3. Numbers — the non-regression gates

Load 10–16, under the machine lock. `--time` prints the phase line
(with a held/total count) only when the derivation does real work; a
full cache hit — `check` or `build`, nothing left to read — prints one
line naming the command and `cache hit`, no count. The one figure
this table doesn't otherwise carry: `check cli --time`, run once right
after `build` has warmed the store (so `check` itself has not read
these sources yet), holds `288/289` — one file read, the entry — and
a second `check` in a row is then a cache hit too.

| | 09-19 | now | gate |
|---|---|---|---|
| `build cli` cold | 22.7 s | ~10–13 s | 16 s |
| `build cli` no-op | 0.4 s | **0.08 s** | 0.3 s |
| `build cli`, one body edit | 1.2 s | **0.31–0.40 s** | 0.5 s |
| `build cli`, a generic's home edited | — | ~1.4 s | 3 s |
| `check cli` no-op | 9.7 s | **~0.04 s** | 0.2 s |
| `check cli`, one edit | 9.7 s | **~0.18 s** | 0.5 s |
| `check std-avrac` | 11.6 s, RED | cold 13 s · warm ~1.5 s, clean | 2 s |
| `test std-json` | 1.6 s | cold 1.7 s · warm 0.25 s · one edit 0.7 s | 1 s |
| `test std-avrac` (5314 cases) | ~40 s | cold 38 s · warm 13 s, all of it the RUN · one edit 16.7 s | — |

One-edit `check`, ms: startup 15 · load 36 · mint/fill 26 · parse+typing ~20 ·
lower 16 · keep 16. A warm build adds emit 8 · link 110 — the link is the floor
(hello-world links in 44, `-lLLVM` adds 29, the 288 objects 46).

## 4. Keepers, instruments, protocol

- `make cache-attacks` (in the gate, ~40 s): programs and a library through ONE
  store, 62 builds, 27 under a hold, each binary held to the evaluator, which
  reads no cache. It counts holds and refuses zero. A new hold bug is a new step.
- `sh tools/hold_sweep.sh [pkg] [filter]`: every source touched, one at a time,
  built through the hold, filed by class in `build/hold-sweep.out`. Not in the
  gate; run after any change to the hold, the records or the keys; drive to zero.
- `--time` names each file a record knows that was READ anyway, with why
  (`Reads`: entry, home owed, text moved, nothing kept, const gone, unholdable,
  run by another file). A thin hold explains itself.
- `make census CMD="…"` runs COLD (it sets `.avra-cache` aside).
- Profiling a 0.4 s run: `sample` attaches too late. Derive N times in one
  process (a throwaway loop, never committed) under `AVRA_SAMPLE=8
  AVRA_SAMPLE_AFTER=1 sh tools/watch.sh 4000 ./avra build <pkg>`.

```sh
cp build/avra build/avra.pre            # the way back
sh tools/watch.sh 4000 make avra        # ONE generation per run
./avra build packages/cli --time
make cache-attacks                      # after any hold or key change
# seed law: commit source -> make seed -> commit the seed -> seed-check at HEAD
```

- `index N is out of bounds` naming no file → the evaluator
  (`compiler/backend/interp.av`): a settled const or lifted annotation whose shape moved.
- `make seed` fails while the tree builds → `./avra emit packages/cli` is stricter.
- `check <pkg>` counts its DEPENDENCIES' defects. Dedup by identity; name the scope.
- A compiler under test stands in `build/`, or it finds no std root.
- `./avra run` of a lone file under a tree picks up the TREE's `avra.toml`.
- A commit touching a seed-hashed source (packages, runtime, backend C) owes
  `make seed`; `seed-check` compares HEAD to HEAD, so run it AFTER the commit.

## 5. Laws this work paid for

Each is a law and the instance that bought it. CLAUDE.md holds the general
doctrine; these are the ones that live at this layer.

**Keys and holds**
- **Move the content, not the key.** A key over lowered bodies never matches a
  file that is never lowered; make the content a function of what the key reads.
- **One derivation.** A hold decided by CONTENT whose shape came from a record
  keyed by NAME let one program read another's stale lines (`Bar has no field y`).
- **Held by NAME is held by accident.** A held `impl` aimed at every record of
  its target's name; the record keeps the declaration it aims at.
- **A symbol outlives every id a run hands out.** `spec$<DeclId>` would have
  answered to another file's number; case symbols are content-stable.
- **An object reads more than interfaces the day it bakes a value in.** A
  foreign const's VALUE is in its interface line; a const that RUNS a fn folds
  the text of every file it can see.
- **The binary's key covers the closure the last derivation ADMITTED**, not the
  toolchain: one compiler edit used to miss every suite in the tree.
- **The link's order is the sources'**, never the hold's: one tree, one binary.
- **No key folded the compiler**, so a codegen fix never reached a held body. A
  hand-kept format number is moved by nobody; the store is named by the bytes.
- **"No telling" is not "nobody".** A binary younger than two seconds has no
  stamp; read as "no compiler" it went to a shared store, silently. A fallback
  that WORKS is the dangerous one.
- **Two ways to make an object are two objects under one key.**
- **A list that only grows is a hold that only shrinks.** A file's record keeps
  what ITS runs read, never what any run ever read.
- **A guard sized to the symptom un-holds the innocent.** "A program that boxes
  a flat record builds whole" took the hold from a whole suite; the layout
  belongs in the interface.
- **One module, two spellings, two records.** Imports are canonical.

**A whole hold** — true only while something was always read (`f2f955d`)
- **A registry is a value, and an entry built over a copy types nothing.** With
  every file held nobody had interned even `int`; the program's `main` is a
  RECIPE built over the registry that links it — a link asked again of the
  sources is another workspace, with other type and file ids.
- **A held module nobody read is never minted**, so what the entry calls there
  has no declaration but the one the program's module brings (`CaseHome`).
- **The prelude is every module's import, written by none**: a held module
  admits the packages its `use` lines name, so nothing admitted it.

**Instruments**
- **The gate never edits a file**, so it cannot see a hold wrong for an edit
  nobody tried. The sweep touches every file.
- **A suite that never held attacked nothing.** 22 green steps at `held 0/6`.
- **A sweep that asks "clean?" does not ask "held?".** The hold collapsed to
  25/292 on correct builds.
- **A guard over a filtered list is always false** (`files.any(is_held)` over
  the non-held files).
- **A refused hold hid a native crash**; the differential caught it because the
  evaluator reads no cache.
- **A cache can cost more than what it keeps.** A type-wire memo doubled `fill`;
  a stamp row per file lost to reading the file. Measured, reverted.
- **The watchdog cost the warm build more than the build** (80 ms of work, 0.3 s
  of a poll).

**Records**
- **A text record spends its separators.** A case's name is any sentence; a line
  break in one un-held its module. **The empty name is a name.** **The root
  module's name is empty, and `split` drops a trailing empty field.**
- **A memo keyed on nothing answers for the day it was filled** (the extern
  symbols, gathered before the last `use` admitted its package).
- **Two copies of a law disagree the day one moves** (flat over ONE `int` in
  typing, over any scalar in the record loader).
- **A nested declaration is no symbol.**
- **A workspace is an identity, never a value.** A restart from a copy keeps
  every hold. **A restart from the sources that can restart is a loop** — 6 GB
  in a minute; `unheld` refuses the second.

**Memory**
- **A read pinned the box a later write opens.** `if m.get(k) == null {
  m.set(k, v) }` cloned the WHOLE map per insert — a third of the compiler's
  samples. The borrow scan reads through a bracket opened since the load
  (`leaves_or_changes`); a self-owning child rides nobody (`takes_twin`). Proof:
  `features/mutation/tests/borrows`, each shape witnessed trapping with the scan removed.
- **A parameter is borrowed** (+0): `standing_regs`; a view is lent and retained
  across a call; the callee's answer and keeps take their own reference
  (`features/fns/tests/borrowed_params`).
- **A box dangles only when its PLACE holds the only reference.** A hostile
  shape sets the place in a scope that has CLOSED, or it bites nothing.
- **`mut x = self.xs[i]; x.set(..); self.xs.set(i, x)` COPIES** — the element is
  held twice while written.

**Queries and derives**
- **A whole-program pass never runs inside a resolve** — `receivers()`,
  `method_diagnostics` and the RECEIVERS pass are each guarded.
- **An incomplete query result must not be memoized** (`methods(target)` cached
  empty while resolving).
- **`resolved` is a recursive query**: `start_recursive`; a smaller view
  re-enters and contributes nothing.
- **The per-file report renders over every loaded source** — a homed `Loc` may
  name a dependency's file.
- **A derive is worth its machinery when N readers ask ONE question**, never
  when N readers ask questions that agree on most inputs. `Type` has forty
  exhaustive matches; three look alike and disagree at `Ptr`, `Null`, `Struct`,
  `Opt` by design (the statement is at `rides_pointer`).
- **An annotation that cannot mean its declaration must say so THERE.** A
  `@derive` on the wrong kind made an empty record and blamed 43 callers.

**Builds and merges**
- **A merge of two lanes that BOTH moved the compiler needs a ladder of its
  own**: neither parent's binary reads the merged tree. Land one side's engine
  as code written WITHOUT the new spellings, then merge.
- **A target must depend on what it links** (`seed-check` without
  `$(RUNTIME_OBJS)`: green warm, fatal cold).
- **A fixture naming an absolute path is a platform claim** (`/usr/bin:/bin`).
- **A bad pattern propagates by being the nearest example to copy; two
  consumers adapting to one seam means the seam is wrong.**

## 6. Compile time — the decisions that stand

What departs from the spec, so reconciling them is a decision and not a surprise:

1. **No `@lifted`/`@comptime` mark on fns.** The stage is the CALL's (`const`,
   an annotation site, a `const` seat). "Lifted" survives as the manifest section.
2. **`@derive` lives on the trait**, as its `static fn derive`; `@derive` is std code.
3. **The answer type is the effect** — a metadata annotation cannot sneak codegen, by type.
4. **Stacking is innermost-first.**
5. **An annotation sees declarations as VALUES, never tokens.** (The formatter
   design reopens one clause: a `quote` in pattern position.)
6. **No keyword registration.** Sublanguages are a consumer (`grammar { }`, a
   lifted builder), not a second mechanism.
7. **`${}` replaces `~`**; quote kinds are inferred. **No `@expand`.**
8. **Purity is a registry column** (`Reach`), not a deny-list of C names.
9. **`Code` is typed by KIND, untyped by T** (`Code`/`Stmts`/`Arms`/`Decls`). A
   template body is not typed at the quote, so `Code<int>` would be checked only
   where the generated code is typed anyway. Reopen only with typed holes.
10. **Construction is one-directional**: `Directive { twin, source }` and one
    materializer — a registry of directive kinds, never an encoder/decoder mirror.

**Leave-alones, each with what would reopen it:**

| stays by hand | because | trigger |
|---|---|---|
| the child walk (`expr_children`, `stmt_exprs`) | 2 of 30 arms are semantic (`Quote`, `Sublang`); a derive would answer silently for the next such variant | a payload MARK naming semantic children |
| the 16 per-feature `kids()` | each hides children under its own narrowing | none — semantic |
| the IR's consumers (`step`, `memory_ins`, `emit_ins`, …) | exhaustiveness IS the vocabulary's guarantee | none — the design |
| `semantics_of` / `Dispatch` | the one map makes "features never import features" checkable | a measured cost |
| the five `*_of_meta` projections | their default is deliberate; the value protocol's absence is a defect | none |
| `quotes_at`, `body_starts` keyed by a stringified id | map keys are strings (`type.applied`) | an int-keyed map |
| the lexer's two raw-body scanners | they differ on `//`, correctly | a third copy |
| `source_text.av`'s precedence scale | the grammar states precedence as nesting, no number | the derived printer (formatter phase 4) |
| a shared `param` grammar rule | two forms today | a third seat mark or param-taking form |
| exhaustive dispatch (`fingerprint_stmt` …) | must break when a variant lands | none |

### 7b. Cache, after the merge

- **S8 `avra_snapshot`** — freeze a closure-free value, thaw it immortal;
  `Parsed` qualifies. Cold paths only (parse is 3 s of a cold build), and what
  puts `run`/`emit`/`ir` on the derivation. Needs a builtin: `snapshot<T>`
  cannot be written, a record does not fit a `ptr` seat.
- **The parser's fast path** — `grammar/executor.av` builds a farthest-failure
  record per failed terminal, and a PEG fails most alternatives.
- **A verdict kept beside a suite's binary** — `test std-avrac` warm is 13 s of
  running binaries nothing moved. Sound only for a hermetic suite: wants
  `[test] hermetic = true` and `--rerun`. OWNER'S CALL.
- **The program's module is WRITTEN to be keyed** (~300 ms of a home's edit). A
  fold over its IR must cover every register's type by shape, every static and
  extern, or it is the hash that forgets a payload.
- **No-daemon startup levers**: an mmap'd snapshot of warm state, lazy libLLVM
  load, trimming keep/lower. `holdable` decodes every declaration at load (~10 ms).
- THE SEAL IS WHOLE-PROGRAM (avra-8sb5.21): a `mut` seat boxes a flat record
  from any file; the root fix is an inout ABI. **Unprobed beside it:** a fn that
  STARTS writing its receiver under a hold — does any key see it? Write the attack.
- A `dyn` field boxes only where the trait is imported (avra-8sb5.22).
- A lone file outside a checkout has no prelude (avra-8sb5.20).
- The program module's key folds the entry's instructions and not its register
  types (`program_asked_key`) — sound only while the instructions decide them.
- A record naming a deleted file un-holds its module for one build.
- **A hold once REFUSED a correct program** — `check` on a moving source tree,
  old compiler: "field `read` is `List<ReadFile>`, this is `List<iface_digest>`"
  (a fn name where a type belongs); `rm -rf .avra-cache` cleared it. A refusal
  under a hold is asked again of the sources, so this one survived the re-ask
  or never reached it. Unreproduced; write the attack.
- A held non-entry file with top-level statements is not refused until read;
  its record should say it RUNS.
- `program_key` folds tests: a test edit misses the binary.
- A file object's key folds neither `opt` nor the runtime's identity (the
  program's module does).
- The receiver seal scans every statement per impl (`writes_receiver`,
  `typing/impls.av`; `Survey.assigns`, `receivers.av`) — wants a statement-range query.
- `methods(target)` forcing a whole-file resolve: cost and cycle-safety never measured.
- `codes.av` never moved into `diagnostics/`.
- **Vision, unbuilt:** semantic addressing (key a body on its NORMALIZED IR:
  commutative operands ordered, registers α-renamed, dead code dropped — only
  the guard that `avra_array_get`/`_owned` must NOT be equal exists) ·
  observed invalidation (field-level reads, so a hash cannot forget a payload).

### 7c. Derives and the crossing

## 8. Refused, with the reason

- **Per-function codegen units** — once the hold works they buy ~30 ms on the
  one edited file and cost thousands of objects at link and every cross-fn
  inline at `-O1` (P4). Their other half, in-process object emission, LANDED.
- **`ld -r` prelinking, `ld` without the driver** — save 8 and 5 ms.
- **A type-wire memo in fill, a stamp row per file** — measured slower.
- **`World`/`Compiled`/`Projection` types and their traits** — a trait with one
  verb and three callers is ceremony; `derived(entry, want)` IS the verb.
- **A resident compiler** — no daemon; the owner's word.
- **Type-shape marks** (`@scalar`, `@boxed`, `@flat`) — three properties that
  correlate, not one property with three readers (§5).
- **A free-fn derive form; quotes as raw strings; text-origin hygiene** — each
  superseded by parsed templates with per-node origins.
