# FLOW 01 — waiters, gates, task rows, the per-task slot: design note
Ticket `avra-8sb5.34.53.1`; base `89ea7f7`. Nothing here is built or run: every number is ESTIMATE unless marked MEASURED, and none is MEASURED. `f:` is `runtime/avra_fiber.c`.
**Today (READ).** A `Fiber` has one `next`, one `parked_fd`, one `timer` (f:125-138); the heap holds one entry per fiber and is never stale (f:201-206); descriptor lists hold fibers and adding walks to the tail (f:287, f:358-364); an edge wakes EVERY waiter and readiness is a level bit (f:392-397, f:419-423); join files the fiber on `TASK_WAITERS` and ignores the deadline, as sleep does (f:733-749, f:802-808); a virtual task is the same struct (f:869-878) and its park is a second copy of the native body (f:825-845 vs f:911-930); the yield path reads no waiter state (f:604-610, f:796-800).
## 1. Structs
```c
typedef struct Waiter { struct Waiter* next; struct Waiter** link;  // its source's list; link NULL = not filed, so unlink is O(1)
    Fiber* fiber; int32_t arm, member; uint32_t kind;               // W_FD_R, W_FD_W, W_AT, W_GATE, W_DEADLINE
    union { int fd; size_t timer; void* gate; } on; } Waiter;       // 48 B; `on` is what `avra tasks` and G2 print as waits-on
struct Fiber { /* today's sp, map, task, next, joining, state, deadline, virtual */
    uint8_t claimed, parked; int32_t arm, member;                   // THE SET: one live set per fiber, so it lives in the fiber
    Waiter held[4], due; Waiter* more; uint32_t held_n;             // four inline, the deadline's own, an overflow list
    uint64_t id; Fiber* all_next; Fiber** all_link;                 // G4 id (addresses are reused); G2 walks every live task
    uint32_t cancel_by; uint8_t unwinding;                          // G3 / slice 3: who asked; set only at a cancel point
    void* slot[4]; };                                               // §4
// A GATE is a record, as a task is (f:140-145): cells {HEAD, TAIL, OPEN}. A TASK IS A GATE with more cells after:
enum { GATE_HEAD, GATE_TAIL, GATE_OPEN, TASK_FIBER, TASK_BODY, TASK_ANSWER, TASK_AT, TASK_CELLS };  // OPEN replaces TASK_DONE
```
`Waiter.set` of the spec is `Waiter.fiber`: a fiber is parked in one place. Spawn site = the body's code address, already in the task (f:684-685); no return address is read. `Timer` becomes `{at, seq, Waiter*}`; a fiberless `avra_task_at` is a heap entry naming a task. `Fiber` grows ~80 B → ~400 B, `FIBER_HEAD` 128 → 448 (f:461).
## 2. The claim machine
`IDLE → ARMING (rows register waiters) → PARKED → CLAIMED(arm, member) → resume: unlink every waiter of the set (retract) → IDLE.`
- `claim(w)`: set claimed → answer 0, the caller moves on; else write `(arm, member)`, ready the fiber if PARKED, answer 1. One `ready_push` per set, ever. A claim during ARMING makes the park return without a switch.
- A source ready at registration claims at once: an OPEN gate (a done task), an unwatchable descriptor (today "ready now", f:836-840), a deadline already past — tested FIRST, before any readiness (f:828).
- `fd_ready` claims every waiter in the direction and skips claimed sets; nothing is lost because readiness stays in `ready` (f:394). `fd_closing` claims as readiness, `fd_interrupt` as the deadline (f:810-823).
- CANCEL (`avra_task_cancel`): writes `cancel_by`, then `claim(-1, 0)`. A set already claimed is not displaced: the task resumes on its arm and takes. The deadline claims `(-1, 1)`. `unwinding` is slice 3's. No timer is stale: resume takes each unclaimed waiter out of the heap, as `unpark` does today (f:376-386). Old rows keep their behaviour: sleep and join park WITHOUT the deadline waiter; `avra_wait_park` always has it.

## 4. The per-task slot — a FIXED TABLE OF FOUR, not one pointer
`void** avra_task_slots` lives in `avra_runtime.c` beside `avra_fd_drained_hook` (the standing precedent for the scheduler reaching into the core object, `avra_runtime.c:3247`), pointing at a static main table; `switch_to` repoints it (one store per switch). So a program that never spawns links no scheduler, and wasm carries it (`Makefile:236` drops only the fiber and cores objects). Keys are one C enum: 0 the relation asker, 1 the flow scope, 2–3 free. WHY A TABLE: `@std/relation` and `@std/task` cannot import each other, so one pointer needs a third owner of its layout; four slots keep a read one load, with no hash and no allocation. A new task's slots are null (not inherited; the deadline still is, f:708); each is released when the task ends. Cancel bits, id and deadline stay C fields: the scheduler reads them at C speed. This DIFFERS from the DB note's "ONE managed pointer … behind a row pair" (`origin/db-engine` note §5.3 rule 1) by one `key` seat — the lead must rule.
## 5. Trace (G4) — `AVRA_FLOW_TRACE=1` (stderr) or a path
`spawn id parent site` · `park id src…` (`fd:r:7`, `at:<ns>`, `gate:<addr>`, `task:<id>`) · `claim id by arm:member` · `wake id cause` (arm, deadline, cancel, closing, interrupt) · `retract id n` · `end id cause`. Flag settled in a constructor (pattern: `avra_runtime.c:1830-1835`); each site is `if (unlikely(g_flow_trace)) cold_fn(…)`, `noinline cold`. NO site in `run_next`, `switch_to` or `avra_fiber_yield`: a switch is not an event. Bytes written are capped in the runtime (`AVRA_FLOW_TRACE_CAP`, default 256 MiB, then one "capped" line); the tools run it under `tools/capped.sh`. Proof: `objdump -d --disassemble-symbols` of the yield and park leaves, frame ops before the first branch, before and after.

## 9. Risks
1. **"No Bell caller changed" cannot hold as written.** `server.av:834-836` files `b.heard.get()` — a descriptor — with `Drain`, and a stop wakes it by `Conn { fd }.interrupt()` (`server.av:277`); with no descriptor `heard` is −1 and `set_at(-1)` is reached (UNPROBED). Proposed: `Drain` keeps the bell and a stop `rouse()`s it — a ~6-line caller change. `sse_test.av:150,160` assert `heard == -1` and hold trivially.
2. An `Unhosted` row answering a managed pointer through the evaluator's uniform frame (`avra_gate_new`) is UNPROBED; fallback: hosted `GateNew`/`GateClaim` arms.
3. `FIBER_HEAD` 448 B is carved from every stack top; the 10k-alive and memory rows pay it. Fallback: two inline waiters.
4. Slice 01 ships `avra_task_cancel` with no unwind: only the C test calls it before slice 3. And `ffi.c`'s static staging area expires when an extern parks inside C (`FIBERS_DESIGN.md:240-243`): `avra_wait_park` is called from Avra, never from package C — a rule, not a check.
