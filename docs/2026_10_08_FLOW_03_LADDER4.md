## The byte and the switch
- New `uint8_t avra_tick` (atomic, relaxed) beside `avra_unwinding` (f:315); a lost tick costs one period.
- TODAY the switch's "is anything due" is a clock read: `if (g_timers_len > 0) { now = now_ns();
  ages_noted(now); fire_due_timers(now); }` (f:1443-1446; base f:1098, the design's f:1100). Ladder 4
  gates that block on the byte beside the countdown the switch already keeps (`g_until_poll`/`FAIR_TURNS`,
  f:539/f:541): the fast path becomes `avra_tick ? cold : (--g_until_poll > 0 ? queue_alone() : cold)` —
  one `cmpb $0,avra_tick(%rip)` (1.6 ns, MEASURED) instead of `now_ns()` (29.4 ns, MEASURED; flow-02 §5
  measured 23.3 ns). `AVRA_TIMER_TURNS` bounds a due timer's lateness to 64 switches or one tick,
  whichever is sooner; it rides the existing countdown, so the fast path gains no instruction (ESTIMATE
  0.46 ns/switch = 29.4÷64). The `while` back-edge read is the compiler's (`Ins.FlagRead`, ladder 7;
  emitted at 15) — not this step.

## The platform seam

  `avra_tick_armed()` / `avra_tick_stood_down()` there.
- The hosted thread lives in its OWN object outside the `runtime/*.c` glob (`RUNTIME_OBJS`,

  neither. OPEN: confirm the path and the Makefile rule.
- `wanted`: the scheduler stores 1 where a task runs with others ready or a deadline standing
  (`switch_to`, f:1369) and 0 as it enters its poller (`next_with_world`, f:1436 / `poller_wait`,
  f:846). The thread reads `wanted` each period and parks after 8 unwanted ones; one wake re-arms.
  Re-arm in `avra_fiber_forked` (f:2027; a forked child saw no tick). The thread sleeps and stores the
  byte only — no alloc, no lock, or a fork can inherit a held libc lock.
